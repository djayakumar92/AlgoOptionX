## First reviewable implementation batch

DATA-01/DATA-02 establish pure quality/causal aggregation without switching current autonomous behavior or risk limits. This batch is deliberately concrete so user review can precede new runtime changes. Its code should be presented with source-bound tests and independent review before subsequent policy/strategy activation. The first batch does not require the absent ebook, live data, payment accounts or a trained model.

## Blockers and parallelizable read-only work

- Missing `docs/references/CANDLE STICK PATTERN EBOOK.pdf` blocks actual book extraction and page/illustration/source verification. It does not block source audit, dependency design, safe data contract planning or a reviewed migration fix.
- New pattern definitions are provisional; source reconciliation precedes executable algorithm implementation.

- Licensed historical chain/bid-ask/expiry data, provider rights, legal reviews, real prospect/pilot participation, payment/hosting/broker access and externally protected deployment policy cannot be invented. Work proceeds only within actual authorized interfaces.
- Human gate: the supplied Phase1 restriction says to present the complete plan and wait for explicit approval before implementation. This package makes that decision concrete; no AI-authored manifest or passing test represents it.

The current request initiated execution of the planning sequence, not a claim that all future business, research and live stages are already done.
