## Method and scope

Indexed all **289 tracked files**, including 103 Python files, static quoted TypeScript imports, native and legacy skill references, configurations, tests and visual assets. The [machine-readable inventory](repository-inventory.json) records per-file SHA-256, size, line count, Python symbols/line numbers and TypeScript imports. Indexing is complete; semantic review focused on financial transactions, temporal data use, decision composition, ingestion, migrations and harness authority. This is not a claim of line-by-line manual verification of every third-party/library behavior. No ignored `.env`, broker credentials or user databases were read.

Code presence, local regression success, historical predictive validity and external production readiness are separate evidence levels. The existing Python suite was actually run on this baseline: **336 passed, one existing synthetic-fixture skip**, with a Starlette/httpx deprecation warning. The skipped prediction test is not evidence that its edge case passes. Browser checks and builds observed on merged PR #3 are historical baseline evidence; no new browser design or live broker operation was verified by this audit.

## Disposition vocabulary

KEEP preserves a bounded working capability; ENHANCE adds explicit acceptance/coverage; REFACTOR changes internals while preserving behavior/history; REPLACE is a proposal requiring a compatible migration and review; REMOVE is never executed without documented justification and explicit approval; NOT VERIFIED means the claimed external or empirical behavior has not been established. No removals are recommended or authorized in this audit.

## Priority findings and containment

1. **AUD-01 / High — destructive legacy journal migration.** A temporary synthetic legacy table with one row was passed to the migration; the table was absent afterward. No production database was accessed. Reachable from research `connect()`, older table shape triggers DROP. The reviewed test file does not establish row-preserving upgrade behavior. Proposed task SAFE-01 stages a backup, maps legacy rows losslessly, verifies counts/identities and aborts unsupported schemas without deleting anything. Keep users off automatic old-database upgrades until fixed and tested.
2. **AUD-02 / High — temporal confirmation must be explicit.** `find_swings` uses future right-hand neighbors relative to the pivot timestamp; that is legitimate delayed confirmation only if consumers respect when it becomes known. `resample` returns the last aggregated bucket without an as-of completeness contract. Never feed those retrospective pivot labels or partial buckets into past decisions. Design `event_at`, `bar_close`, `available_at`, `as_of` and prefix-invariance tests.
3. **AUD-03 / Medium — multiple decision semantics.** The paper rule, combined research vote, setup evidence grade and calibration report have different units/meanings. Introduce a versioned observation/decision envelope rather than average unlike scores or silently swap active behavior.
4. **AUD-04 / Medium — risk target mismatch.** Current 1% initial-capital trade budget and 2% initial-capital loss lock differ from proposed 0.5%/1% equity targets. Version limits per session, define a stable equity basis and migrate via explicit new-session policy; do not reinterpret old fills.
5. **AUD-05 / Medium — synthetic execution is intentionally limited.** No margin/reservation/defined-risk spread engine, intrabar order simulation, exchange lot calendar or genuine historical bid/ask path. Local replay validates accounting, not real-market expectancy.
6. **AUD-06 / Medium — hosted boundaries absent.** No user authentication/tenancy/billing, production SLOs or trusted model registry. Local origin checks are not a substitute. Keep current run bound locally; don't host it as a SaaS without the later gated design.
7. **AUD-07 / Not verified — visual/empirical/legal assurance.** Current screenshots are candidates, legacy research citations are not newly checked, missing ebook was not read, licensed data and legal review are unavailable. No certification or paid demand has been demonstrated.

8. **AUD-08 / High — first-start funding can partially commit.** `Engine.__init__` starts `tx()` and then calls SQLite `executescript`, which implicitly commits that transaction before schema statements. A temporary-DB fault injected into the first `_event` left one account and one active pointer but zero events after the constructor failed. Restart sees the active pointer and does not reconstruct FUNDING. Existing entry/close rollback tests do not prove bootstrap atomicity. SAFE-02 separates schema setup from one explicit account/active/FUNDING transaction and adds failure/restart tests. This finding was reproduced without application edits or user-data access.

## Completion and preservation

The full tracked inventory and targeted domain assessment are complete for the pinned baseline. Tests ran only against fixtures/temp databases, without broker calls. Historical evidence is retained, and no dependency installed or strategy changed during this phase. Planning output does not resolve the eight findings by itself.
