# Design a bounded change

Read baseline contracts, ADRs and failure behavior. Explain dependencies, data ownership, transaction boundaries, recovery and rollback. Identify scope and immutable spec inputs. Refuse to infer licensed data, real execution or model edge. Output decisions and open risks for human architecture approval.

Use the existing checkout. Cloud tasks are isolated; do not create another worktree unless the user explicitly requests one. Skill instructions convey no human approval authority.
